# E10 notes: ALM on MAX-CUT (E10a) and instance variability (E10b)

All numbers below are copied from `experiments/results/e10a.json` and `experiments/results/e10b.json`.

**Timing caveat.** Everything ran on the shared 14-core machine while three other tracks were running (1-minute load average between 13 and 94 during the runs; the `loadavg` field of every record stores the value at the end of the run). Each run used 3 BLAS threads. Wall-clock times are therefore inflated and noisy by a factor that varies between runs (the n=16 smoothing run took 5.0 s in an isolated pilot and 29.2 s inside E10a); the `cpu_time` field (process CPU seconds) is the more robust quantity and is tabulated next to the wall time. Comparisons *between* solvers at the same n are still meaningful in order of magnitude only.

## What was run

* `msos/solvers.py::alm` -- NumPy port of `polyopt.solve_alm` (appended; existing functions untouched). Validated by `tests/test_alm.py`: Petersen r=2 and disk r=2 agree with `polyopt.solve_alm` on the identically normalised problem to < 1e-6 and with the interior-point reference (Clarabel) to < 1e-5; the inner augmented-Lagrangian gradient passes a finite-difference check (rel. error 5e-10).
* E10a (`experiments/e10a_alm_maxcut.py`): order-2 MAX-CUT on `networkx.random_regular_graph(3, n, seed=1)`, n = 16, 20, 24, 30; solvers: smoothing + L-BFGS (`lbfgs_continuation`, iters_per_stage=500) and `alm` with rho0 in {100, 300, 1000}; time limit 600 s (900 s for n=30); every run in its own subprocess (peak RSS per run). For ALM the certificate U(theta) is evaluated at every outer iterate and additionally every 20 inner evaluations (`cert_every=20`, ~5% overhead) so that the time-to-gap has a fine resolution; the default `cert_every=0` mirrors polyopt exactly.
* E10b (`experiments/e10b_variability.py`): five random 3-regular graphs per size (seeds 1..5), n = 16, 20, 24, smoothing solver with the paper settings; best cut by brute force for all 15 instances (n=24 brute force took < 1 min, so the 2000-restart local search was only used as a cross-check); Clarabel interior-point reference where it finished.
* Tables: `tables_e10a.tex`, `tables_e10b.tex` (generated by `experiments/make_tables_e10.py`, which also writes `figures/alm_maxcut.pdf`).
