# E9 — trace cuts, diagonal cuts and the box (track "Cuts")

Script: `experiments/e9_cuts.py` (run from `experiments/`, writes `results/e9.json` incrementally, log in `results/e9.log`).
Tables: `tables_e9.tex` (generated by `experiments/make_tables_e9.py`; two booktabs tabulars, no table environment).
Unit tests: `tests/test_cuts.py` (34 value checks printed as `ok` plus the two strict inequalities trace > diag for box QP n=4 no-box r=1,2; 0 failures).
Code changes: `msos/reference.py` (new `cuts="none"|"trace"|"diag"` argument, Clarabel -> SCS fallback, unboundedness
detection), `polyopt/src/polyopt/solve.py` (new `shift="uniform"|"diag"` argument of `solve_alm`; the `uniform` path is
untouched and reproduces the pre-change values and evaluation counts exactly — test (v) in `tests/test_cuts.py`).
Timings were taken on a shared machine (three other tracks running concurrently, 3 BLAS/torch threads per process) and
are indicative only; the ordering of first-order times between runs varied by up to a factor 4.

## What was run

Interior-point values (Clarabel through cvxpy) of rho_r (no cuts), rho_r^tr (trace cuts) and rho_r^d (diagonal cuts
M_aa <= 1, Mloc_aa <= B_i), the first-order smoothing value U (msos `lbfgs_continuation`, 500 iterations per eta stage,
uniform shift, i.e. the rho^tr side), the dual ALM with the diagonal shift U^d (polyopt `solve_alm(shift='diag')`,
rho0=100, tol=1e-7, time limit 120 s) and, for reference, the ALM with the uniform shift. Instances: box-free example
max x1+x2 s.t. x1 x2=0 (r=1,2,3); box QP n=4,5,6 (seed 1) with and without the n box constraints (r=1,2); random cubic +
quadratic on the ball 1-|x|^2>=0, n=3 (r=2,3, no box constraints); sphere equality max x1+x2 s.t. x1^2+x2^2=1 (r=1,2);
chain quartic n=6 with cliques {i,i+1} with/without box constraints (r=2); Petersen MAX-CUT r=2 (Boolean).
Part B: box QP n=4..10, r=2, 'with box + uniform shift' (n+1 blocks) vs 'without box + diagonal shift' (1 block).

Observations.
* Whenever the box is encoded in the constraints (box QP +box, ball, sphere, chain +box) or the problem is Boolean, the
  three relaxations coincide to solver accuracy (|differences| <= 2e-8): the cuts are inactive.
* Without the box constraints the plain relaxation is unbounded in every case (box-free, box QP, chain), the trace cuts
  give a finite but loose value and the diagonal cuts give exactly the value of the formulation with the n box
  constraints (box QP: 6.33737 / 8.61100 / 15.44526 at both orders; chain: 1.65685), i.e. one moment block with
  diagonal cuts replaces the n localizing blocks. For the box-free example the diagonal cuts are strictly tighter from
  r=2 on: rho^tr = 1.33839, 1.28872 vs rho^d = 1.18921 = 2^{1/4}, 1.12246 = 2^{1/6} (r=1: both sqrt 2).
* Accuracy of the first-order values w.r.t. the interior-point values (Part A, 22 problem/order pairs):
  smoothing U vs rho^tr: max 1.2e-4 (Petersen r=2), median 1.5e-5, always >= rho^tr - 1e-7 (valid upper bounds);
  ALM-diag U^d vs rho^d: max 6.8e-7 (box QP n=5, no box, r=2), median 7e-9;
  ALM-uniform U vs rho^tr: max 3.0e-5 (box QP n=6, no box, r=2), median 7e-9.
  So the ALM with the diagonal shift reaches the interior-point diagonal-cut values to <= 1e-6 on every instance, the
  smoothing solver reaches the trace-cut values to 1e-4..1e-6.
* ALM-diag convergence: 2-38 outer iterations, final primal infeasibility <= 9e-8 on all Part A instances, <= 1e-9 on
  all Part B instances except n=5 (6.8e-8); max time 5.5 s in Part A (chain6 +box: 0.6 s, box QP n=6 +box r=2: 5.5 s).
  Part B: n=7 needed 48 outer iterations / 82 s; the others 6-23 outer iterations.

## Implementation notes / caveats

* `moment_relaxation(..., cuts=)`: `trace_cuts=True/False` are kept as aliases of `cuts='trace'/'none'`. Unboundedness:
  status `unbounded`/`unbounded_inaccurate` or a value > 1e6 -> `float('inf')`. If Clarabel raises or ends
  `optimal_inaccurate`, SCS (eps=1e-8, 1e5 iterations) is tried; if both are inaccurate (this is what happens for the
  box-free example at r>=2 and for box QP n>=5 without box at r=2: the relaxation is unbounded but has no improving
  *ray*, the value grows like |y|^(1/2r), so interior-point solvers return 'optimal_inaccurate' with moderate values
  such as 135 or 16.6), a big-M probe is run: the problem is re-solved with M_aa <= 1e4 and M_aa <= 1e8; if the value
  grows between the two (relative 1e-3) the relaxation is declared unbounded, otherwise the second probe value (with an
  inactive cut) is returned. All 'inf' entries in e9.json (stored as JSON null) came from this path or from an explicit
  'unbounded' status (box QP without box at r=1).
* `solve_alm(shift='diag')`: variables (theta, d) with d the concatenation of the per-block vectors d_b (d_b >= 0 for
  'plus' blocks, free for constant-trace Boolean blocks), G_b = Q_b + diag(d_b), objective sigma + sum_b (w_b/s_b) 1^T d_b
  (w_b/s_b = 1 for moment blocks, B_i for localizing blocks; in polyopt B_i = 1 after its constraint normalisation).
  The certified bound at an outer iterate is U^d(theta,d) = sigma + sum_b (w_b/s_b) 1^T d_b + sum_b w_b Phi_b(Q_b+diag d_b)
  (the uniform-shift certificate of Theorem thm:certificate applied to the shifted blocks); Result.U is the best over
  the outer iterates; Result.extra carries d, d_off, U_uniform (best uniform certificate along the path), outer_iters,
  pinf, dinf, dX. Warm start across orders embeds d by zero padding. The stopping test of the diag path additionally
  requires the relative multiplier change dX = ||X+ - X||/(1+||X+||) < tol: with only pinf < tol and dinf < tol (the
  test of the uniform path; dinf measures the accuracy of the inner solve, not outer convergence) the sparse chain
  instance stopped after 9 outer iterations at 1.65740 instead of 1.65685. The uniform path was not changed.
* In polyopt the number of multipliers of the +box formulation is 181/337/.../2872, identical to msos (an earlier run
  that passed `add_box_constraints=True` to a POP already containing the box constraints duplicated them; fixed).
* `tests/test_cuts.py` value checks are at 1e-3 as specified; the ALM-diag values agree to ~1e-8 in practice.
* Nothing failed in the final run (0 solver failures logged); all first-order runs ended before the 120 s limit except
  possibly ALM-uniform at n=7 (118.7 s, converged to 5e-7 nevertheless).
